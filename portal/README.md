# LuMo Ads Captive Portal — Frontend Design Prototype v2

This version uses the exact supplied LuMo Ads logo as the source brand asset:
assets/LumoAds Logo.png

The logo is not redrawn or approximated. The interface uses the supplied asset,
the LuMo brand palette, and generous white space around the brand.

Included pages:
- index.html — Welcome / splash
- 02-register.html — Registration
- 03-consent.html — Consent & privacy
- 04-ad.html — Advertisement / 25-second visual prototype
- 05-connected.html — Connected / success
- 06-retry.html — Failure / retry
- 07-returning.html — Returning user

Important:
This is a front-end design prototype. It does not yet implement real MikroTik,
RADIUS, persistence, API security, consent storage, identity processing, or
server-side advertisement completion verification.
